### 문제
- 이벤트 기간에 메인 페이지에 트래픽이 집중되어 서버 리소스 최적화가 필요
- 무료 셔틀버스 기능 개발
- 신규 티타임 예약 기능 개발
- 관리자툴 유지보수 및 개선

### 해결
- Redis 캐싱을 적용하여 분산 시스템에서 Latency를 1초 이상에서 0.1초로 개선
    - 관리툴에서 데이터 변경시 캐싱 무효화 전략을 통해 실시간으로 반영
- 셔틀버스 중복 예약 방지를 위해 Redis Lock을 사용
    - DB unique(날짜, 시간, 좌석, 상하행) 제약을 통해 중복 예약 이중 방지
- 히든 타임, 수수료 타임 등 신규 티타임 예약 기능 개발
    - 수수료 타임 판매로 연 5억원의 수수료 대납
- 운영팀 분들의 반복되는 업무를 파악하여 선제안하여 자동화 처리
    - 티타임 수동 등록시 복사 등록 기능 추가
    - 신규 티타임 판매시 Slack 자동 알림 기능 추가
    - 업무량 1일 소요 -> 10분 소요로 개선

### 배운점
- 분산 시스템에서 Redis를 활용하는 방법에 대해 배울 수 있었습니다.
- 기능 개발을 통해 회사에 기여하는 경험을 할 수 있었습니다.
- 커뮤니케이션을 통해 타팀의 업무를 자동화할 수 있다는 부분을 배울 수 있었습니다.
